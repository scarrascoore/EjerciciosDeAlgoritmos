# Simulador-Pseint-Web

Aplicación web inspirada en PSeInt, desarrollada con **React** y **TypeScript**, que permite escribir pseudocódigo en un editor visual y visualizar su ejecución en una consola de salida.

## Características
- Editor de pseudocódigo en la vista izquierda
- Consola de salida en la vista derecha
- Interfaz web moderna y responsiva
- Arquitectura inspirada en **Clean Architecture** y **Hexagonal**
- Base preparada para incorporar intérprete de pseudocódigo

## Tecnologías
- React
- TypeScript
- Vite
- Monaco Editor

## Objetivo
Construir un simulador web educativo que permita practicar lógica de programación con una experiencia similar a PSeInt, pero desde el navegador.
